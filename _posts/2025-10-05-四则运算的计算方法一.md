我们从小学习的四则运算是基于十进制的，但在计算机的世界里，一切都建立在二进制之上。计算机是如何通过底层的硬件逻辑，仅用0和1来完成乘法、除法这些复杂运算的呢？

本文将讲解笔者对**进位标志位 (Carry Flag)**的理解。


> [!NOTE] 
> CPU中的寄存器
> 
> 在开始之前，让我们先认识一下执行运算的几个核心硬件单元：
> * **ACC (Accumulator - 累加器):** 核心计算单元，用于存放操作数和中间计算结果（例如部分积的高位）。
> * **MQ (Multiplier-Quotient Register - 乘商寄存器):** 顾名思义，在乘法运算中，它开始时存放**乘数**，结束后存放乘积的**低位**。
> * **X (Operand Register - 操作数寄存器):** 用于存放另一个操作数，在我们的例子里是**被乘数**。
> * **C (Carry Flag - 进位标志位):** 一个只有1位的特殊寄存器，专门用来捕捉加法运算中超出寄存器位宽的**进位**。它是CPU**程序状态字(PSW)**的一部分。



我们将以 `1011` (十进制 11) 乘以 `0110` (十进制 6) 为例，看看计算机内部发生了什么。最终结果应为 66，即 `0100 0010`。

**初始化状态:**
* **X (被乘数):** `1011`
* **ACC (部分积高位):** `0000`
* **MQ (乘数):** `0110`
* **C (进位标志位):** `0`

运算的核心逻辑是：**检查MQ的最低位，如果为1，则ACC加上被乘数X；然后将C-ACC-MQ整体逻辑右移一位。重复此过程，直到所有乘数位都被检查完毕。**

| 步骤 | 判断位 | 操作 | C | ACC | MQ |
| :---: | :---: | :--- | :-: | :---: | :---: |
| **初始** | | | 0 | 0000 | 0110 |
| **1** | `0` | 仅右移 | 0 | 0000 | 0011 |
| **2** | `1` | `ACC = ACC + X`, 右移 | 0 | 0101 | 1001 |
| **3** | `1` | `ACC = ACC + X`, 右移 | **1** → 0 | **1**000 | 0100 |
| **4** | `0` | 仅右移 | 0 | 0100 | 0010 |

> [!TIP] 
> 关键步骤详解 (第3步)
> 
> 这是整个过程中最关键的一步，也是我们讨论的起点。
> 1.  **加法运算:** 此时 `ACC` 的值是 `0101`，`X` 的值是 `1011`。执行加法 `0101 + 1011` 得到 `10000`。
> 2.  **进位处理:** 这是一个5位的结果！ACC本身只有4位，无法存下。此时，结果的低4位 `0000` 被存入ACC，而最高位的 `1` 则被存入**进位标志位C**。因此，加法完成后，状态为 `C=1`, `ACC=0000`。
> 3.  **逻辑右移:** 接下来，将 `C-ACC-MQ` 这个“虚拟”的9位寄存器整体向右移动一位。之前存入 `C` 的那个 `1`，现在顺理成章地被移入了 `ACC` 的最高位。
>
> 这个设计精妙地解决了加法溢出和数据移位的问题，确保了计算信息的完整性。

**最终结果：**
4轮过后，运算结束。最终的8位乘积由 `ACC` (高位) 和 `MQ` (低位) 拼接而成：
`0100 0010` (十进制 66)，计算完全正确！

----

我们已经知道进位标志位在乘法中的妙用，但它的角色远不止于此。

#### 普通加法中的进位

对于一条简单的`ADD`指令，例如计算 `1001` (9) + `0111` (7)：
* **计算结果:** `1 0000`
* **CPU状态:** `ACC` 会被更新为 `0000`，同时 `C` 标志位被设置为 `1`。
* **作用:** 程序可以检查 `C` 标志位来判断无符号数加法是否**溢出**，或者利用它来进行**多精度运算**（比如在32位机器上计算64位数）。

#### 结果如何存入主存？

> [!IMPORTANT] 
> CPU寄存器 vs. 主存
> 
> 这是一个非常重要的区别：**进位标志位 C 不会和 ACC 的值‘捆绑’在一起存入主存。**
>
> * 当你执行一条 `STORE` 指令（例如，将ACC的值存入内存地址`0x1000`），只有 **ACC** 中的数据（例如 `0000`）会被复制到内存中。
> * `C` 标志位是 **CPU内部的状态**，它描述了**上一步运算**的属性。它不会随着`STORE`指令被写入主存。
>
> 只有在发生**中断或操作系统进行任务切换**时，为了完整保存当前程序的运行“现场”，CPU才会通过特殊指令将包含 `C` 在内的整个**程序状态字(PSW)**寄存器作为一个整体存入内存（通常是堆栈）。

| 组件 | 角色 | 如何存入主存 |
| :--- | :--- | :--- |
| **ACC** | 存放数据 | 通过 `STORE` 等常规指令直接写入 |
| **C Flag** | 描述运算状态 | 不随常规指令写入，需通过特殊指令保存整个PSW |

### 总结

1.  二进制乘法可通过“加法和移位”的循环来实现。
2.  **进位标志位(Carry Flag)** 是解决运算过程中临时溢出的关键，它衔接了加法和移位操作。
3.  `C` 标志位是CPU的**内部状态**，反映了运算的结果属性，而 **ACC** 等寄存器则存放**数据本身**。在与主存交互时，这两者是被区别对待的。
