## 一个猜想：用纹理频率检测解决COD问题

紧接着上一阶段的复盘：我通过FCN、U-Net和SINet的对比，认识到COD的困难之一来自于目标和背景过于相似，浅层特征有可能对网络造成干扰。U-Net实验也初步说明，普通分割网络容易出现局部漏检和背景误检。

那么我进一步问自己，比较成功的COD模型发现目标的机制可能是什么？在上一篇复盘的结尾，我提出了一个猜想，如果COD模型依赖的是检测纹理频率的分布差异（这样的假设是很不完善的，最多是依赖之一，是一个线索，不大可能是充分条件），那么我们是不是可以直接构建这个特征并针对性地匹配和检测它？

### 实验设计：前景背景频谱统计

鲁莽地直接训练一个纹理频率检测网络耗时费力，因此我从数据本身出发，观察COD图像中前景目标和邻居背景是否存在可检测的纹理频率差异，以此来验证我的猜想。

首先考虑如何量化地表示所谓“纹理频率差异”。我选择了三个相关特征：

1. 拉普拉斯能量：用于衡量局部高频突变、边缘和细碎纹理强度。它可以理解为一个区域中灰度变化是否剧烈。
2. 局部方差：用于衡量局部对比度或灰度振幅波动。它不直接等同于频率，但可以反映局部纹理是否复杂。
3. Gabor响应：用于衡量方向性纹理响应。Gabor滤波器对不同方向、不同尺度的条纹和纹理比较敏感，因此适合观察叶脉、羽毛、昆虫纹理等结构性差异。

具体代码如下：
```python
def gabor_energy(patch_gray: np.ndarray) -> float:
    """提取 4 个方向、2 个频率的 Gabor 纹理响应均值"""
    responses = []
    for theta in (0.0, np.pi / 4, np.pi / 2, 3 * np.pi / 4):
        for freq in (0.08, 0.16):
	        # 参数gamma=0.5 控制Gabor核的空间纵横比，使其对方向性纹理更敏感
            kernel = cv2.getGaborKernel((31, 31), 4.0 / freq, theta, 1.0 / freq, 0.5, 0, cv2.CV_32F)
            resp = cv2.filter2D(patch_gray, cv2.CV_32F, kernel)
            responses.append(float(np.mean(np.abs(resp))))
    return float(np.mean(responses))

def sample_features(image_gray, region_mask):
    h, w = region_mask.shape
    features = []
    ys, xs = np.where(region_mask > 0)
    if len(ys) == 0:
        return features
    coords = list(zip(ys, xs))
    random.shuffle(coords)

    for y, x in coords:
	    #SAMPLES_PER_REGION是每个区域采样的图块数量，我的代码中取10
        if len(features) >= SAMPLES_PER_REGION: 
            break
        # PATCH_SIZE = 32
        if y + PATCH_SIZE > h or x + PATCH_SIZE > w:
            continue
        patch_mask = region_mask[y:y + PATCH_SIZE, x:x + PATCH_SIZE]
        if patch_mask.mean() >= MIN_PURITY:
            patch = image_gray[y:y + PATCH_SIZE, x:x + PATCH_SIZE]
            lap = float(np.mean(cv2.Laplacian(patch, cv2.CV_32F) ** 2)) #拉普拉斯能量
            var = float(np.var(patch)) #局部方差
            gab = gabor_energy(patch) #Gabor响应
            features.append([lap, var, gab])
    return features
```

然后我定义了三个区域，给定一张COD图像及其Ground Truth遮罩图像，GT内部区域经过一次腐蚀操作后作为前景区域，记为fg；GT膨胀后减去GT的周围一圈区域作为近背景，记为bg_near；取更远的背景区域作为远背景，记为bg_far。通过分析这三个区域，可以比较两组差异，第一组是fg与bg_near，如果目标和邻近背景之间存在纹理频率差异，这组的分布应该表现出显著差别；第二组是bg_near与bg_far，自然图像不同区域之间本来就不可能完全一样，因此这一组作为对照组，如果我的猜想正确，这一组的分布差距应该小于第一组。分布差异使用K-S检验计算。因此核心代码如下：

### 结果分析

读取COD10K中用于训练的CAM图像，共3039张，其中78张目标太小提取不出patch被跳过处理，最终有效处理了2961张，格式化打印K-S检验的结果如下：

```txt

  前景   vs  近背景: D = 0.2192, p = 0.0000e+00
  近背景 vs  远背景: D = 0.1846, p = 0.0000e+00
  信噪优势 (Signal > Noise): YES

特征维度: 2. 局部方差 (对比度/振幅)
  前景   vs  近背景: D = 0.1407, p = 4.3451e-241
  近背景 vs  远背景: D = 0.1317, p = 1.0663e-212
  信噪优势 (Signal > Noise): YES

特征维度: 3. Gabor 响应 (方向性纹理)
  前景   vs  近背景: D = 0.0721, p = 2.8596e-66
  近背景 vs  远背景: D = 0.0392, p = 1.3240e-19
  信噪优势 (Signal > Noise): YES

```

三类特征中，前景与近背景的(p)-value都极小，说明二者在统计上确实不是同一分布。同时三类特征的“前景—近背景差异”都大于“近背景—远背景差异”。这说明目标与邻近背景之间的纹理/频率差异并不只是自然图像中普通区域波动造成的，而是确实存在额外的可测信号。

其中，Laplacian energy的差异最明显，说明伪装目标与近背景之间在高频突变和局部边缘细节上仍然存在差别。Gabor response的绝对 (D) 值虽然较小，但前景—近背景差异几乎接近近背景—远背景差异的两倍，这说明方向性纹理可能是一个值得关注的低层线索。Local variance的信号优势最弱，说明单纯的局部灰度波动并不是很稳定的判别依据。

这个结果可以支持我猜想的前半部分：COD图像中确实存在前景伪装目标与邻近背景之间的纹理频率分布差异。

### 贝叶斯误差

前景—近背景虽然有显著差异，但 (D) 值并不接近1，说明同时也存在大量重叠区域。换句话说，许多前景patch和背景patch在特征空间里的表现非常接近。对于这些重叠区域，仅凭这个频率特征无法判断它到底属于目标还是背景。

这些重叠导致的分类误差，可以用贝叶斯误差来衡量。通过有放回采样，取全变差距离TVD估计值的95%分位数作为经验上界$U$，即可得到经验的贝叶斯误差下界：$P_{e} \gtrsim \frac{1}{2}​(1−U)$.

```python
def estimate_tvd_overlap(x0, x1, bins=64):  
	data = np.concatenate([x0, x1])  
	hist_range = (data.min(), data.max())  
	  
	p0, edges = np.histogram(x0, bins=bins, range=hist_range, density=False)  
	p1, _ = np.histogram(x1, bins=bins, range=hist_range, density=False)  
	  
	p0 = p0 / p0.sum()  
	p1 = p1 / p1.sum()  
	  
	tvd = 0.5 * np.sum(np.abs(p0 - p1))  
	overlap = np.sum(np.minimum(p0, p1))  
	bayes_error = 0.5 * overlap  
	return tvd, overlap, bayes_error 
	 
def bootstrap_tvd_upper(x0, x1, bins=64, n_boot=1000, alpha=0.05, seed=42):  
	rng = np.random.default_rng(seed)  
	tvds = []  
	  
	for _ in range(n_boot):  
	b0 = rng.choice(x0, size=len(x0), replace=True)  
	b1 = rng.choice(x1, size=len(x1), replace=True)  
	tvd, _, _ = estimate_tvd_overlap(b0, b1, bins=bins)  
	tvds.append(tvd)  
	  
	return np.quantile(tvds, 1 - alpha)
```


计算结果，$\frac{1}{2} (1-U) = 0.393$ ，这意味着，即使使用该频率特征上的理论最优分类器，仍至少有约 39.3%的样本会因为前景与近背景分布重叠而无法被正确区分。妄图直接训练纹理频率分类器解决COD问题的思路并不现实。

## SINet核心机制再解析

上一次复盘我已经了解了SINet用来先搜索再识别的仿生学思路，其搜索模块使用多分支感受野结构和空洞卷积，确实会捕捉不同尺度下的局部纹理和上下文信息。多尺度感受野可能帮助模型比较目标区域与背景区域之间的纹理差异。

但结合这次实验结果来看，SINet的关键或许不是单纯检测某种纹理频率，频率检测只能帮它确定一个低层特征与周围不一致的大致区域，然后再进一步判断这些区域是否存在一个完整目标。这也解释了为什么SINet要分成SM和IM两个模块。

具体到SM模块，即使被描述为“粗略搜索”，实际上也经过了高层和底层的相互验证。SM模块入口处有四个关键层，它们的输出分别是x1,x2,x3,x4，对应从浅到深的特征。网络并没有直接把它们输出RF模块，而是进行了复杂的拼接操作，得到x1_cat,x2_cat,x3_cat，这种构造多尺度上下文的方式，可以让模型同时看到局部细节和全局语义。这些拼接后的信息（加上x4本身）进入RF模块，它改自RFBNet的Receptive Field Block，可以在不改变空间尺寸的情况下，用不同分支捕捉不同感受野（体现在不同空洞率）的信息，然后把它们融合。

上一次复盘中提到部分解码器（PDC）在IM模块中起到重要作用，利用类门控的机制保证浅层特征必须被深层语义和中层语义共同筛选后才能认为是可靠的。实际上网络中共有两个PDC模块，SM的RF输出后的结果都要进入其中一个我们称之为PDC_SM的块中。这也很契合之前的实验结论，浅层特征不能全信，必须和深层相互验证。

由此可见，SINet并不因为它讲了一个仿生学故事就有效，它的结构确实对应了COD图像的特点。不过这也暴露了SINet的局限性，它仍然主要依赖CNN的多尺度感受野和局部上下文建模，当目标与背景在纹理、颜色、边界上都高度接近，或者背景本身存在大量与目标类似的低层异常时，SINet仍然可能出现漏检和误检，SINet并没有彻底解决“低层线索不唯一”的问题。


## FEDER：从“寻找异常”到“分解判别特征”

顺着这个思路，接下来我顺理成章地选择了阅读FEDER这篇论文。它的视角是分开解决两个问题：IS，前景和背景太像导致定位困难；ED，边缘太模糊导致分割困难。听上去和SINet很像，但本质有所不同，解决IS问题的部分相当于直接完成了SINet，ED则是更精细的边缘重建，因此在论文中，FEDER的表现比SINet要更好一些。

FEDER很好地解决了我之前实验中产生的问题，既然纹理频率作为判别线索确实存在，但又不完全靠谱，那么模型就不应该把所有特征混合处理，而是应该先分解再筛选再聚合。

FEDER由三个大模块，Camouflaged Feature Encoder(CFE), Deep Wavelet-like Decomposition(DWD), Segmentation-oriented Edge-assisted Decoder(SED)组成。其中，CFE也和其他网络类似，先把原图变成多层CNN特征。论文中基础编码器$E$使用了ResNet50/Res2Net50，这些特征的空间分辨率会逐级下降，每一层都用R-Net（沿用自SINet）转换成紧凑特征$\{f_k^r\}_{k=1}^{4}$，四个紧凑特征都是64通道数的，只是尺寸不同。这很方便于后面的频率分解和解码。

DWD是FEDER最核心的模块。论文认为COD中可区分前景和背景的细微信息可能藏在不同频率成分里，高频部分对应纹理和边缘，低频部分对应颜色和光照。因此它对$f_{k}^r$做了可学习的小波变换。

小波变换也是一种图像处理方式，它不像傅里叶变换只保留频率信息，而是能同时保留频率的空间信息。之所以能做到这一点，就是因为把无限延展的三角波换成一个局部有限会衰减的小波，从而可以用平移变换的变量来对应空间信息。小波的局部支撑或快速衰减特性，使局部突变造成的影响不会像傅里叶级数那样扩散到整个信号。在DWD中，类小波并不是完全严格的小波，不一定满足全部数学约束，但目的和作用都像小波变换，其滤波器参数在训练中更新。这种结构比起普通卷积，类小波变换本身具有一定物理结构，很容易把信息分成高频和低频来分别处理，这正契合作者所需要的——高频分量对应纹理和边缘，低频分量对应颜色和亮度。

这就引出了DWD中的几个小模块。High-frequency Attention(HFA)处理高频特征获得纹理和边缘信息，利用注意力机制生成一个注意力图。Low-frequency Attention(LFA)处理低频特征获得颜色和亮度的分布，并提供更干净的全局信息，并从全局视角突出异常区域。Guidance-based Feature Aggregation(GFA)在注意力的引导下，把多尺度的频率特征聚合起来，让深层语义和浅层细节互相补充。论文说，GFA不是简单拼接特征，而是更细微的特征识别。

最终，识别出的特征并不会一股脑地全部解码，而是只选择有效的聚合结果送入SED中。SED获得聚合结果和经过e-ASPP变换的$f_{4}$特征（来自CFE最后的输出），相当于直接获得了两个模块的学习结果，便能从粗到细解码，每一层同时做分割和边缘重建。

由此可见，我之前“纹理频率检测器”的想法确实充满局限性。COD中的差异不一定只表现为高频更强，也可能表现为低频分布的轻微异常，比如目标区域整体亮度、颜色分布、阴影关系和周围背景不完全一致。而单纯的频率分布检测很容易陷入到只看局部patch频率的陷阱中，从而把复杂背景当作目标。

从这个角度看，FEDER能够比SINet更进一步，在于它更关注差异所在的具体特征成分。它不只是扩大感受野，也不只是做注意力，而是从频率分解的角度重新组织特征，把COD中的判别线索拆成高频和低频，再通过注意力和特征聚合选择有用部分，最后通过边缘重建补充目标边界。

这也解释了为什么 FEDER 会选择小波式分解，而不是普通的高频滤波。传统高频滤波只能告诉我们哪里变化剧烈；但可学习类小波分解可以在深度特征空间中学习更适合 COD 的频带划分。它保留了小波分析高低频分解的先验，又让这种分解适应具体任务。

## 总体复盘与下一步计划

通过这次复盘，我对COD模型发现目标的核心依赖有了更具体的认识。第一次复盘中，我主要关注的是COD和普通语义分割的差别，而这一次复盘则进一步理解了COD模型的机制。通过重读SINet和新阅读的FEDER，我发现COD图像中确实存在前景与邻近背景之间的纹理/频率分布差异，这种差异可能是COD模型利用的重要低层线索；但这种线索本身不稳定、不唯一，也不足以单独完成目标检测。真正有效的COD模型需要把这些低层差异放进上下文、尺度、形状和边界结构中进行筛选和组织。
